# Half-screen window snapping (experimental)

Use Super+Left / Super+Right to snap the focused window into either half of its current display. Dragging a window to an edge also snaps; repeating the same keyboard shortcut restores the original geometry. Does not modify fullscreen or unmanaged windows. This PR is a standalone source change against DEsk 0.1.5, not an AiO feature installer. Compile and runtime regression tests are required before merging.
