# Visual Alt+Tab switcher (experimental)

Shows a compositor-owned window list while Alt+Tab is held. Includes folded-window labels, keyboard navigation with arrows, Enter or Alt release to accept and Escape to cancel. The popup does not depend on window snapping or other experiments.

This PR contains only the independent visual switcher port, not the AiO installer. It may overlap upstream shortcut proposal #8. The exact source anchors matched DEsk v0.1.5, but compilation and interactive testing are still pending.
